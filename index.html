01 · ADII

A number looks wrong.
Changing it is a separate decision.

ADII investigates the number and answers: fix it, leave it, or escalate it. The AI that proposes a fix can’t approve it. Two programs outside the model decide whether the change is allowed and whether it holds.

Team research: a paper and a complete reference implementation that runs locally, not deployed in production.

Not every answer is allowed.

03 · CytherCAD

Language in.
Valid geometry out.

Describe a part. CytherCAD turns that description into instructions that build it, restricts invalid geometry during generation, and checks the result afterwards. It runs on-prem, private and air-gapped.

CytherAI’s product: validated by CytherAI’s own test, with no deployment claimed.
