01 · CytherCAD · Geometry

Language in.Only valid geometry out.

CytherCAD turns text into CAD. The model proposes a construction program token by token; a boundary refuses every token that breaks the grammar or the geometry, and an independent kernel rebuilds whatever closes. 0.00% invalid outputs on Text2CAD-192 — an external benchmark, published, not operated by CytherAI.

03 · AWC-OS · Money

The model writes it.The engine decides.

AWC-OS is a constitutional financial-intelligence layer. A model writes a financial program; a deterministic symbolic engine executes it, refuses it, or blocks it — with a replayable receipt either way. Success is not an answer every time. It is unauthorized answers failing safely.

04 · SijilOS · Records

Nothing is overwritten.Ever.

SijilOS is an event-sourced ledger for the Saudi market. It stores intent over time, not just the current state: a correction is a new event, and history is never edited. ZATCA Phase 1 certified (April 2025), live beta in two production environments, fully offline-capable.
