# icon-v1 — the derived mark, retired

The favicon and app icons every page and the web manifest named from commit `5e3f51a` until 2026-10-13: the densest
filament of the canonical CytherAI orbit (`CytherManifest.CANON`), ink on cold paper, DERIVED by `derive-icon.py` from
the manifest. They were replaced by the Cyther Seal (`tools/render-seal.py`), computed from the company's name, when
the owner adopted the seal identity. Their receipt, IMG-002, stands in `docs/asset-promotion-log.md` with its output
paths moved here, and `tools/test-assets.py` still verifies these bytes against it. Nothing here is served.

`derive-icon.py` is kept as it was, as the record of the method. It imports `pngout` and `canon` from its own
directory, which this snapshot does not carry, so it does not run here.
