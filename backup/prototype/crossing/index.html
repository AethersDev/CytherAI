01 · The model proposes

The model is allowedto be wrong.

Beneath the glass, forty proposers fire drawing tokens upward — move across 4, move up 1, close the shape. Here they are hostile on purpose: random tokens, almost all of them wrong. In a CytherAI system a model has no authority. It can only propose.

02 · The boundary judges

Every token is judgedbefore it exists.

The glass is the boundary. Each token is checked against the grammar, then the geometry. A refused token lights the glass where it struck and names the rule it broke. Nothing is filtered afterwards — what fails never becomes an output.

  • Axis order0moves must alternate: across, then up
  • Arg range0a step longer than four
  • Grammar0not a word of the drawing language
  • Closure0closed too early, or with no straight line home
  • Crosses0the drawing would cross itself
  • Bounds0leaves the 12 × 12 field
  • Closing cross0the line home would cross the drawing
  • Closure axis0the line home runs along the wrong axis

03 · A second opinion

Then an independentkernel checks it again.

When a program closes, a kernel that shares nothing with the boundary but the rules rebuilds it from nothing. Only when both agree does the geometry cross — blue while it is checked, white once it is verified. Every solid above the glass passed both. Hover one: it is judged again, now, in your browser.
