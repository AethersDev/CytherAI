COLOPHON · HOW THIS PAGE WORKS

One font. Two axes. Zero images.
Every effect on this page is font-variation-settings driven by three inputs — cursor proximity (field), scroll velocity through a critically-damped spring (tension), and a travelling gaussian pulse (specimens). Each glyph carries its own current/target state and eases toward it every frame, which is why the type feels like cloth instead of a switch. Roboto Flex · ~190 live glyphs · one requestAnimationFrame loop that sleeps when the type is at rest.
