CytherAI’s lead product

CytherCAD — Controlled Generative CAD

Compact autoregressive model producing executable parametric construction programs. Constrained decoding restricts invalid geometry at generation time. Kernel-backed verification checks the geometry after generation.

VerifiedCytherAI’s evaluation log
ContextOn-prem · Private · Air-gapped
MethodologyAutoregressive generation · constrained decoding · kernel-backed geometric verification
Test set192 descriptions chosen by CytherAI from the Text2CAD dataset (Khan et al., NeurIPS 2024)
StatusCytherAI’s product: validated by CytherAI’s own test, with no deployment claimed.

CytherAI’s second system

SijilOS — Offline-First Ledger

Transactional ledger for the Saudi market, running on the device and fully offline-capable, with no cloud service at its core. It produces the QR code that ZATCA’s Phase 1 e-invoicing rules require. No certification, deployment or pilot is claimed.

ArchitectureOn-device · Offline-first
Cloud dependencyNone at its core
E-invoicingZATCA Phase 1 QR code, produced on the device
StatusNo certification, deployment or pilot claimed
The founder’s public work

MenuMind — A Grounded, Memory-Aware Restaurant Assistant

It learns each customer’s preferences from conversation and recommends real dishes from a fixed menu. The model only describes what was said, as typed claims; eleven ordered rules in code decide what is saved, asked or ignored, and an allergy is removed only after a yes to the app’s own question.

ByMalek Alhazmi
On record197 tests with no model calls; on gpt-5.4-mini, 42 of 42 test conversations fully correct and no unsafe recommendation in 75 turns (13 October 2026). These are counts, not rates, and the app has changed since that run.
StatusA demonstration on a fictional restaurant’s menu, not a production deployment; it makes claims about declared recipes, not medical allergy safety.

The founder’s public work

Barker Sequences — Two Companion Papers

Number theory, on a conjecture open since 1965. The census paper classifies the 421 minimal covering configurations of size at most 6 over the first 80 hard primes, and proves a cofactor-cycle theorem; the realization paper proves the exact law by which the associated residue matrices occur.

ByMalek Alhazmi
On recordBoth papers, their source and a verification suite, public
StatusTwo papers, public and frozen for review: neither closes the conjecture, and no new Barker obstruction is claimed.

A team project

ADII — A Data-Incident Agent

The AI that proposes a fix can’t approve it: each fix must pass an authorizer and an independent validator. It led to the paper Permission Is Not Justification, whose result is that guardrails can hide a bad agent.

ByGroup 05: Malek Alhazmi (team lead), Joorie Alsakran, Ibrahem Altowalah and Nasser Alzaid
StatusTeam research: a paper and a complete reference implementation that runs locally, not deployed in production.

A team project

AWC-OS — Financial Programs, Decided by an Engine

A fine-tuned model writes a program for each financial question; a separate, deterministic engine runs it, refuses it with a Sharia-compliant alternative, or blocks it.

ByAl-Baseera (البصيرة), presented at the AMAD 2026 FinTech Hackathon
StatusTeam demonstration: the MVP runs on an evaluation machine, not on deployed hosting.
